# Gatherly — 90-second product demonstration

Record the working application after live AI is configured. This is a recording script, not a completed video.

| Time | On screen | Suggested narration |
| --- | --- | --- |
| 0–10s | Overview | “Meet Gatherly, a thoughtful planning assistant for weddings, birthdays and community events.” |
| 10–25s | Create a birthday: Kochi, 30 guests, ₹25,000, future date, vegetarian picnic | “Tell Gatherly what you’re celebrating, where, when and how much you want to spend.” |
| 25–40s | Budget; change an allocation and spending | “The budget adds up exactly, with contingency included. Track real spending and see what remains.” |
| 40–52s | Timeline; check a task and add a custom task | “A dated checklist turns the plan into clear next steps.” |
| 52–63s | Vendors; enter a fictional demo vendor and quote | “Keep shortlists, quotes, booking status and questions in one place.” |
| 63–80s | Ideas studio; generate live and ask a real follow-up | “AI uses the event details to suggest personal touches and practical alternatives.” |
| 80–90s | Export; closing overview | “Export the plan, keep the details organized, and make room for the celebration.” |

Only show successful real AI output as AI output. Label any examples, use fictional vendor information, and do not expose credentials, personal messages or guest data. Upload to unlisted YouTube or a reviewer-accessible Drive file, then test the link without signing in.
